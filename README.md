# healthcare-analytics-powerbi-dashboard
🏥 Hospital Performance Tracker | Power BI Data Analytics Project

## Project Overview
This project demonstrates an end-to-end healthcare analytics solution using Power BI. The dashboard provides actionable insights into hospital operations, patient management, revenue generation, and doctor performance.

# Objective
The objective was to transform raw healthcare data into interactive visual reports that support data-driven decision-making.

## Tools Used
- Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- 
## Business Problem
Hospitals generate large volumes of operational and patient data. Without proper analysis, it becomes difficult to monitor performance, identify bottlenecks, and improve patient care.

This project addresses these challenges by creating an interactive dashboard that tracks key healthcare metrics.

## Key KPIs
- Total Patients
- Patient Admissions
- Occupancy Rate
- Revenue Analysis
- Treatment Outcomes
- Average Length of Stay

## Dashboard Features
### Executive Overview
- Hospital Performance Summary
- Revenue Trends
- Occupancy Monitoring

### Patient Analytics
- Admission Trends
- Discharge Analysis
- Treatment Success Rate

### Revenue Analysis
- Monthly Revenue
- Revenue by Department
- Revenue Trends
